# ТРЦ Европейский — Сборка для публикации

## О проекте

Это статическая версия сайта торгово-развлекательного центра «Европейский» для публикации на хостинге. Все ресурсы (HTML, CSS, JS, изображения, видео) собраны в папке `dist` с корректными относительными путями.

## Структура папки

- `index.html` — главная страница
- `pages/about.html` — страница «О ТРЦ»
- `pages/shops.html` — страница «Магазины»
- `css/` — стили сайта (`main.css`)
- `js/` — скрипты сайта (`main.js`, `navigation.js`)
- `img/` — изображения для сайта и магазинов
- `icons/` — иконки и логотипы
- `video/` — видео для главной и страницы «О ТРЦ»

## Как использовать

1. Загрузите содержимое папки `dist` на ваш хостинг или сервер.
2. Откройте файл `index.html` в браузере — сайт будет работать полностью локально, все ресурсы подключаются по относительным путям.
3. Для перехода между страницами используйте меню навигации.

## Важно

- Все пути к ресурсам уже настроены для работы из корня папки `dist`.
- Для корректной работы видео и изображений убедитесь, что структура папок не меняется.
- Для работы карты Яндекс на странице «О ТРЦ» требуется актуальный API-ключ (замените `YOUR_API_KEY` в about.html на свой ключ).

## Состав

- HTML: Главная, О ТРЦ, Магазины
- CSS: Адаптивная верстка, стили для всех страниц
- JS: Навигация, анимации, фильтры магазинов
- Изображения: фотографии ТРЦ, магазинов, логотипы
- Видео: ролик о ТРЦ
